# LƯỜI ENGLISH — Audio Assets Directory

Directory structure:
- `audio/ui/` (click, back, correct, wrong, open, close)
- `audio/rewards/` (star, chest, level_up, achievement)
- `audio/mascot/` (hello, good_job, try_again, lets_go)
- `audio/vocabulary/` (grade-specific vocabulary pronunciations)
- `audio/sentences/` (sentence & chunk audio clips)
- `audio/stories/` (story narration audio)
- `audio/conversation/` (dialogue audio)
- `audio/ambience/` (treehouse, island acoustic ambience)
