# LƯỜI ENGLISH — Phased Product Roadmap

This document outlines the 12 evolutionary phases for LƯỜI ENGLISH from bootstrap foundation to enterprise-grade child learning ecosystem.

---

### PHASE 0: Foundation Bootstrap *(Current Phase)*
- [x] Repository topology, documentation, and anti-gravity AI workspace.
- [x] Strict TypeScript domain types (Curriculum, Student, Memory, Reward, Pet, AI).
- [x] Dual-Theme token engine (`cozy` vs `explorer`).
- [x] Semantic asset & audio registry.
- [x] Domain Engines: Spaced Repetition Memory Engine, Server-Trusted Reward Engine.
- [x] Repository Abstraction Layer (In-Memory + Firestore blueprints).
- [x] Sample Grade 3 Unit ("Hello & Friends") data seed.
- [x] Next.js 15+ full-stack foundation with passing typecheck, lint, and build.

---

### PHASE 1: Parent & Child Identity + Theme Selection
- [ ] Parent authentication (Email/Password, Google OAuth via Firebase Auth).
- [ ] Multi-child profile management under single parent account.
- [ ] Child theme selection (`cozy` vs `explorer`) with instant visual preview.
- [ ] Age/Grade configuration (Grade 1–5).

---

### PHASE 2: Curriculum Foundation
- [ ] Hierarchical curriculum data loader and indexing engine.
- [ ] Knowledge Graph nodes for vocabulary, chunks, phonics, and grammar patterns.
- [ ] Grade 1–5 unit and lesson browsing service.

---

### PHASE 3: Learning Player
- [ ] Multi-activity interactive engine (Listen & Repeat, Word Match, Choose Right, Fill Chunk, Mini-conversation).
- [ ] Audio synthesis and playback controller with replay, speed control (0.8x, 1.0x).
- [ ] Real-time activity validation and instant encouraging feedback from Chú Lười.

---

### PHASE 4: Reward Ledger & Pet Companion
- [ ] Server-trusted reward ledger (Stars, XP, Coins, Pet Food).
- [ ] Chú Lười Pet companion: Egg Hatching → Baby Sloth → Young Explorer → Master Sloth.
- [ ] Pet feeding, bonding, and cosmetic customization.

---

### PHASE 5: Adventure Map & World Hub
- [ ] Interactive visual map with unlocked learning nodes and treasure chests.
- [ ] Product World Hub: Adventure Map, School, Skills, Talk to Lười, Story World, Media World, Game Land.

---

### PHASE 6: Cognitive Memory Engine
- [ ] Real-time Spaced Repetition queue calculation per student.
- [ ] Active recall flashcards and weakness detection.
- [ ] Daily memory review challenges.

---

### PHASE 7: Speaking & Safe AI Tutor
- [ ] Web Speech API / Server-side Whisper speech-to-text evaluation.
- [ ] Chú Lười AI Tutor: 4-tier scaffolded hints (`Hint 1 -> Hint 2 -> Example -> Answer`).
- [ ] Pronunciation phoneme accuracy scoring.

---

### PHASE 8: Story & Media World
- [ ] Read-along interactive storybooks with synchronized audio highlighting.
- [ ] Media player for curated kids English news, songs, animations, and shadowing exercises.

---

### PHASE 9: Educational Game Land
- [ ] Mini-games targeting grammar structures and vocabulary reflexes.
- [ ] React-based game components and optional Phaser integration for rich arcade mini-games.

---

### PHASE 10: Parent Insights Dashboard
- [ ] Comprehensive reporting on active time, speaking minutes, listening exposure, and vocabulary mastery.
- [ ] Weakness detection breakdown and actionable parent coaching recommendations.

---

### PHASE 11: Admin Content Factory
- [ ] Content creation studio: Curriculum Builder, Unit Manager, Lesson Builder.
- [ ] AI-assisted lesson drafting with mandatory human educator review gate.

---

### PHASE 12: Security, Performance & Scale Hardening
- [ ] Strict Firestore security rules and audit logging.
- [ ] Rate limiting on all AI endpoints.
- [ ] Offline caching and PWA service worker.
