## 1. The Dual-Track Learning Model

A critical flaw of standard learning apps is treating all language proficiency as a single monolithic percentage (e.g. "85% English mastery").

In the Vietnamese education reality:
- **Case A**: A student scores 10/10 on school written exams but freezes when speaking to a foreigner.
- **Case B**: A student speaks naturally and intuitively but struggles with school test grammar rules.

**LƯỜI ENGLISH evaluates both tracks independently**:

```
┌─────────────────────────────────────────────────────────────┐
│                    KNOWLEDGE MASTERY PROFILE                │
├──────────────────────────────┬──────────────────────────────┤
│ 1. School Curriculum Score   │ 2. Communication Competency  │
│    (GDPT 2018 / SGK Test)    │    (Natural Fluency / CEFR)  │
│    • Word spelling           │    • Pronunciation & Phonics │
│    • Grammatical accuracy    │    • Listening comprehension │
│    • Reading matching        │    • Spontaneous utterance   │
└──────────────────────────────┴──────────────────────────────┘
```

---

## 2. Multidimensional Cognitive Mastery Matrix

Every `KnowledgeMastery` record tracks 7 cognitive dimensions (0 to 100):

| Dimension | Description | Measurement Activity |
| :--- | :--- | :--- |
| `recognitionMastery` | Can identify word/sentence meaning when presented. | Multiple choice, Flashcards, Word matching. |
| `listeningMastery` | Can comprehend natural audio speech without reading text. | Audio tap, Listen and pick, Audio dialogue. |
| `speakingMastery` | Can produce target chunk/sentence orally. | Speech recognition, Repeat aloud, Roleplay. |
| `readingMastery` | Can decode and understand written English sentences. | Sentence reading, Story comprehension quiz. |
| `writingMastery` | Can spell words and construct grammatical sentences. | Fill in chunk, Sentence unscramble, Typing. |
| `pronunciationMastery`| Accuracy of phonetic articulation and intonation. | Phonics tap, IPA consonant/vowel accuracy. |
| `applicationMastery`  | Can deploy language in spontaneous real-world dialogue. | AI Tutor conversation, situational challenge. |

## 3. Contextual Recall Variants (Spaced Repetition Anti-Fatigue)

Instead of repeating the exact same multiple-choice question on every review cycle, the `MemoryEngine` selects diverse **Contextual Recall Variants**:

```
Cycle 1: Flashcard / Audio Recognition
  ↓ (Correct)
Cycle 2: Speaking Challenge with Chú Lười
  ↓ (Correct)
Cycle 3: Real-world Situational Dialogue
  ↓ (Correct)
Cycle 4: Interactive Story Riddle
```
