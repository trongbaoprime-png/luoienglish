# Frontend Skill for LƯỜI ENGLISH

## Rules:
- Build components in `src/components/`.
- Never import Firebase directly in reusable UI.
- Use `ThemeProvider` and semantic classes for theme switching.
- Support both `cozy` and `explorer` visual treatments seamlessly.
- Animate with Framer Motion using kid-friendly spring parameters.
