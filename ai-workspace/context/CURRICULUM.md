# LƯỜI ENGLISH — Curriculum Context for AI Agents

## Data Hierarchy
Curriculum -> Grade -> Semester -> Unit -> Lesson -> KnowledgeItem -> Activity

## Knowledge Item Types
`vocabulary`, `chunk`, `grammar`, `pronunciation`, `communication_function`, `listening_pattern`, `reading_pattern`, `writing_pattern`.

## Cognitive Stages
Every knowledge item is tracked across 6 stages:
1. `recognize`
2. `recall`
3. `understand`
4. `use`
5. `produce`
6. `transfer`

All content is structured purely as data fixtures or database documents, never hardcoded inside UI components.
