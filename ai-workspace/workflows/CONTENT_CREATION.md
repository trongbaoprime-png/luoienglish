# Content Creation Workflow

1. **Pedagogical Brief**: Define Target Grade, Unit Topic, Knowledge Items, and Communication Goals.
2. **Data Model Construction**: Write TypeScript content schema adhering to `Curriculum` -> `Unit` -> `Lesson` -> `KnowledgeItem` -> `Activity`.
3. **Phonics & Audio Mapping**: Map semantic audio and illustration IDs to the registries.
4. **Educator Review**: Validate that activities follow Word → Chunk → Sentence → Conversation, and verify 100% original IP.
5. **Publish**: Add to `src/content/` seed registry.
